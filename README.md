# 💡 Система Предиктивного Обслуживания Уличного Освещения (Predictive Maintenance)

Проект разработан в рамках хакатона **IT-Tupolev 2026**.

Это ML-решение предназначено для прогнозирования вероятности поломки уличных фонарей (LED) на основе телеметрии. Система позволяет переходить от реактивного ремонта к проактивному обслуживанию, экономя бюджет и повышая надежность городской инфраструктуры.

## 🚀 Основные возможности

*   **Генерация синтетических данных**: Умный скрипт создает реалистичные датасеты (100,000+ записей), имитируя износ оборудования от скачков напряжения, температурных перепадов и времени работы.
*   **ML Модель (XGBoost)**: Классификатор, предсказывающий вероятность отказа лампы в ближайшие 7 дней.
*   **Интерактивный UI (Streamlit)**: Полноценная панель управления для аналитики данных, обучения модели и ручного тестирования.
*   **REST API (FastAPI)**: Сервис для интеграции с фронтендом (3D-картой города).

## 🛠 Установка и Запуск

Для управления зависимостями используется современный и быстрый менеджер пакетов `uv`.

### 1. Предварительные требования
Убедитесь, что у вас установлен Python. Рекомендуется использовать `uv` для скорости, но можно и стандартный `pip`.

### 2. Настройка окружения

```powershell
# Создание виртуального окружения
uv venv

# Активация окружения (Windows)
.venv\Scripts\activate

# Установка зависимостей
uv pip install -r requirements.txt
```

## 🖥️ Использование UI (Streamlit Dashboard)

Это главный инструмент для демонстрации работы модели жюри и тестирования гипотез.

**Запуск:**
```powershell
streamlit run dashboard.py
```
После запуска автоматически откроется браузер (обычно http://localhost:8501).

### Описание разделов UI:

#### 1. 📊 Dashboard (Главная)
Обзор текущего состояния инфраструктуры.
*   **Метрики**: Общее количество ламп, прогнозируемый процент отказов.
*   **Статус модели**: Показывает, загружена ли обученная модель.
*   **Быстрая статистика**: Средние значения показателей по всему городу.

#### 2. 📈 Data Explorer (Исследование данных)
Инструмент для аналитика данных.
*   **Просмотр данных**: Таблица с сырыми данными телеметрии.
*   **Матрица корреляций**: Тепловая карта, показывающая связи между признаками (например, как сильно скачки напряжения влияют на поломку).
*   **Гистограммы**: Визуализация распределения любого признака (например, температуры) для исправных и неисправных ламп.

#### 3. 🤖 Model Training (Обучение)
Центр управления моделью.
*   **Кнопка "Train Model"**: Запускает переобучение XGBoost на текущем датасете прямо из интерфейса.
*   **Метрики качества**:
    *   **ROC-AUC**: Интегральная метрика качества (чем ближе к 1.0, тем лучше).
    *   **Confusion Matrix**: Матрица ошибок (сколько поломок мы угадали верно, сколько ложных тревог).
*   **Feature Importance**: График, показывающий, какие факторы (скачки напряжения, часы работы и т.д.) модель считает самыми важными для предсказания поломки.

#### 4. 🔮 Interactive Prediction (Интерактивный тест)
"Песочница" для ручной проверки.
*   Вы можете вручную двигать ползунки и менять параметры лампы (часы работы, циклы включения, температура).
*   Система мгновенно пересчитывает вероятность поломки.
*   **Индикация риска**:
    *   🟢 **GREEN**: Норма (Вероятность < 40%)
    *   🟡 **YELLOW**: Предупреждение (Вероятность 40-70%)
    *   🔴 **RED**: Критический риск (Вероятность > 70%)
*   **Анализ причин**: Модель объясняет, почему риск высокий (например, "High thermal stress" или "Excessive voltage spikes").

## 🔌 Использование API (FastAPI)

API предназначен для интеграции с веб-фронтендом или мобильным приложением.

**Запуск:**
```powershell
python app.py
```
Сервер запустится на `http://0.0.0.0:8000`.

**Эндпоинт прогноза:** `POST /predict`
Пример тела запроса (JSON):
```json
{
  "hours_active": 8000,
  "on_off_cycles": 3000,
  "avg_temp_exposure": 30.5,
  "temp_fluctuations": 40,
  "voltage_spikes": 6,
  "humidity_exposure": 75.0
}
```

## 🧠 Описание ML Модели

Мы используем градиентный бустинг (**XGBoost Classifier**).

**Входные признаки (Features):**
*   `hours_active`: Общее время работы (часы).
*   `on_off_cycles`: Количество циклов включения/выключения.
*   `avg_temp_exposure`: Средняя рабочая температура (°C).
*   `temp_fluctuations`: Количество резких перепадов температур.
*   `voltage_spikes`: Количество зафиксированных скачков напряжения.
*   `humidity_exposure`: Средняя влажность среды (%).

**Целевая переменная (Target):**
*   `will_fail_in_7_days`: 1 (Сломается) или 0 (Будет работать).
