# 🚁 Инструкция по интеграции ИИ-маршрутизатора (Drone Routing AI Core)

Этот сервис представляет собой ML-ядро для оптимизации маршрутов дронов с учетом **физических параметров полета** (вес груза, разряд батареи) и **погодных условий** (ветер).

---

## 🚀 1. Запуск сервиса

Сервис написан на Python (FastAPI). Рекомендуется запускать его как отдельный микросервис.

### Вариант А: Использование `uv` (Рекомендуется)
Если у вас установлен менеджер пакетов `uv`:
```bash
# Установка зависимостей и запуск
uv run main.py
```

### Вариант Б: Стандартный `pip`
```bash
# 1. Создать виртуальное окружение
python -m venv .venv
# (Windows) .venv\Scripts\activate
# (Linux/Mac) source .venv/bin/activate

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Запустить сервер
python main.py
```

Сервис запустится по адресу: `http://0.0.0.0:8001`

## 📡 2. API Интерфейс

**Endpoint**: `POST /api/v1/optimize`
**Content-Type**: `application/json`

### 📥 Формат запроса (Request)

Система принимает список точек (ламп) и координаты депо (базы).

```json
{
  "lamps": [
    {
      "id": "lamp_123",       // Уникальный ID лампы (строка)
      "lat": 55.751052,       // Широта
      "lng": 48.750037        // Долгота
    },
    {
      "id": "lamp_456",
      "lat": 55.749079,
      "lng": 48.741976
    }
  ],
  "depot_lat": 55.7528,       // Координаты базы (откуда вылетает дрон)
  "depot_lng": 48.7452,
  
  // Опционально: Ручная погода (если не передать, сервис сам запросит реальную погоду)
  "wind_speed": 5.0,          // Скорость ветра (м/с)
  "wind_deg": 90.0            // Направление ветра (градусы, 0=Север, 90=Восток)
}
```

### 📤 Формат ответа (Response)

Сервис возвращает оптимизированный маршрут и расчетные метрики.

```json
{
  "route_ids": [              // Порядок облета ламп (ID)
    "lamp_456",
    "lamp_123"
  ],
  "route_geometry": [         // Готовый массив точек для отрисовки линии на карте (Leaflet/Google Maps)
    [55.7528, 48.7452],       // Депо
    [55.749079, 48.741976],   // Лампа 456
    [55.751052, 48.750037],   // Лампа 123
    [55.7528, 48.7452]        // Возврат в депо
  ],
  
  // 📊 Метрики эффективности
  "total_energy": 24500.5,    // Затраченная энергия (условные единицы)
  "naive_energy": 28000.0,    // Энергия обычного маршрута (для сравнения)
  "savings_percent": 12.5,    // Экономия энергии (%) благодаря ИИ
  
  // 🔋 Физические показатели
  "flight_time_minutes": 14.2, // Расчетное время полета (мин)
  "battery_usage_percent": 35.4, // Расход батареи (%)
  
  // 🌤 Погодные условия, использованные при расчете
  "wind_speed": 3.6,
  "wind_deg": 165.0,
  
  "baseline_algorithm": "Nearest Neighbor (Distance)"
}
```

## 💻 3. Пример кода интеграции (Python)

```python
import requests

API_URL = "http://localhost:8001/api/v1/optimize"

payload = {
    "lamps": [
        {"id": "L1", "lat": 55.75, "lng": 48.75},
        {"id": "L2", "lat": 55.76, "lng": 48.76}
    ],
    "depot_lat": 55.755,
    "depot_lng": 48.755
}

response = requests.post(API_URL, json=payload)

if response.status_code == 200:
    data = response.json()
    print(f"Оптимальный маршрут: {data['route_ids']}")
    print(f"Экономия батареи: {data['savings_percent']}%")
else:
    print("Ошибка оптимизации:", response.text)
```
